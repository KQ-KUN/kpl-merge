## 开局与路线

进入后先显示“选择你的本命战队”，队徽网格展示队徽和 canonical 简称；上次选择可默认高亮，允许更换。点击“开始合成”才创建一局。

用户最新纠正：每局首球固定最低阶L0，L0从LGD/JDG随机选一队；若其一被选为本命则用另一队担任L0，八队互异。本命仍固定L7。开局音乐从本局最低阶L0正常版开始，与首球一致；普通投球不切歌。

固定 8 个物理等级 L0～L7。玩家本命固定为 Level 7；从LGD/JDG随机取一支非本命队伍填入L0，再从其余合格池用Fisher-Yates抽取并排列6支不同队伍填入L1～L6。每局生成后锁定，过程绝不重抽。合成本命L7后立即暂停物理与投放，弹出继续游玩/再来一局；继续保留当前球体和得分，重开彻底清理旧局。本命战歌在弹窗时继续播放，页面隐藏或静音仍停止。本命不能进入中间等级，队伍不得重复。RNG 可注入以便测试。

常驻可见免责声明原文：

> 本局中间队徽随机排列，仅代表球体等级，不代表战队实力、排名或历史成绩。

提供可折叠的“本局合成路线”，所有等级和队徽有顺序关系，突出“最终目标：本命”，不用实力排序措辞。

## 合并与精确计分

仅两个有效、尚未消耗、同等级的物理球可合并；L0+L0→L1，依此至 L6+L6→L7。不同等级永不合并；两颗 L7 永不合并，不创建 L8。新球位于两球中心附近，按质量加权速度保留有限动量并限制突发速度，优先稳定。

自然投放 0 分。只在实际成功合成后按**输出等级**结算一次：

| 输入 | 输出 | 分数 |
| --- | --- | ---: |
| L0 + L0 | L1 | 6 |
| L1 + L1 | L2 | 26 |
| L2 + L2 | L3 | 32 |
| L3 + L3 | L4 | 219 |
| L4 + L4 | L5 | 335 |
| L5 + L5 | L6 | 606 |
| L6 + L6 | L7 本命 | 5408 |

建立唯一 MERGE_SCORES 配置，不拆散或改成数学序列。连锁每次实际 merge 独立累计、独立浮分，例如 L1→L2→L3 总分为 26+32=58，出现两次反馈。逐次加分第一行显示如+26+26+32，第二行显示连锁得分+84；两行都持续保留，直到新组合成或重开。

一次 tick 中一颗球只能被一个合成认领；两个输入先标为 consumed，再从 Matter world 移除并创建输出，最后提交一次规则状态。相邻 tick、共享 body 的多对碰撞和 collisionActive 都不能重复结算。

## 投放与大小

首球固定L0；初期只自然生成L0/L1，权重10/17与7/17，L2权重为0。首次合成L4后才使用L0/L1/L2 = 50%/35%/15%。用户要求延后：首次合成L6后才改用L0～L3 = 35%/30%/25%/10%；首次合成L7后才改用L0～L4 = 26%/26%/26%/14%/8%。L5～L7只能合成，用户明确确认不投放L5/L6。权重集中config，校验总和、合法等级和非负值。升级只影响未来抽样，不改已经显示的current/next；只有成功投放才推进队列，拒绝投放/RNG失败不推进。

物理碰撞体永远是圆。队徽按原始宽高比占满球体直径，统一LOGO.diameterFactor=2，不绘制额外圆形底板或灰色/本命外框。保留原图自带图案；碰撞挤压和合成弹动只影响绘制。等级控制半径，战队不控制尺寸。封面队徽首次失败后带不同URL重试一次，不永久隐藏。

当前调试半径为 [20,28,38,50,64,82,104,132]，世界400×600。用户要求增大球体和难度后不再沿用首八级的小球等比值。数字集中管理，仍未冻结平衡；一个 L7 可正常留场，多 L7仍可存在。

Pointer Events 同时支持 Mouse/Touch/Pen：移动定位，鼠标单击/触摸松手投放，pointercancel 不投放；只处理主 pointer，release 只结算一次，不使用额外 click handler。投放坐标按当前球半径 clamp 在墙内。preview 仅渲染，绝不加入 world。

游戏区域 touch-action:none，避免拖动滚页、双击缩放和 ghost click；页面其他区域仍能正常滚动。键盘左右移动，Space/Enter 投放；控件焦点不触发游戏快捷键。

## 本命反馈与结束

每产生一颗 L7：+5408、本命次数 +1，显示“本命达成！”、战队名称、队徽及明显的短暂放大/光圈和强浮分。支持 reduced-motion，无动态时仍有静态文字；可轻微 vibrate，异常静默。**合成本命不结束游戏**，可以继续合成第二、第三颗；L7 留场作为大型障碍。

游戏结束只判断已释放的真实球：球顶在危险线以上且速度低于稳定阈值持续约 1.8 秒。新掉落与合成输出先经过 grace；弹跳、回线、球被合并都会重置对应计时。连续合成仅延缓参与合成的球，不让无关危险球获得无限保护。preview 不参与。

结束触发后立即禁止新增球、冻结计分与统计，允许世界短暂稳定，再展示结果。计时使用模拟时钟，hidden 或暂停时不把现实离开时间算作稳定越线。

## 界面与记录

2026-10-07第二轮反馈：桌面游戏箱按窗口宽高完整展示，总分在左、本次加分在右；手机将两者紧凑排列在箱体上方。删除可见的L7合成次数和next，当前球preview与内部current/next队列仍保留。分数采用大字记分牌、连锁逐项加分和短弹动；精确计分不变。删除纵向落点辅助线，横向危险线仅预警时显示。浏览器支持时提供进入/退出全屏按钮。返回中心、BEST、本命队徽等后续内容尚未实现。沿用平台 Editorial / Sports Magazine。

结算显示本命、本局得分、本命次数、最高等级所对应队伍、历史最高；至少一颗 L7 时突出“本命达成！”，否则正常结算。提供再来一局、更换本命、返回 KPL GAME。重开重新生成路线，整局不变。

只用 localStorage：schemaVersion、selectedTeamId、globalBestScore、perTeam[teamId].bestScore/maxFinalCount。解析失败、未知 schema、异常字段、访问被禁、配额不足都安全恢复，不阻断开局。保存记录只在状态变更，不每帧写。

合成独立加分显示1200ms，输出球短暂弹动/内部亮度反馈，碰撞和投放180ms挤压仅变绘制形状，碰撞半径不变；不绘制扩散光圈。指针点击Canvas无焦点圈，键盘保留深色焦点标记；reduced-motion取消球体/数字弹动，保留静态得分。冷却进度使用同一模拟时钟；暂停/结束在箱体内明显提示。效果按模拟时钟过期、数量有界；不添加计时器，不每帧造DOM；监听器、RAF、Observer、CSS动画与效果随会话/应用清理。暂停/hidden停物理更新并正确恢复。

## V1 边界与验收

不做账号、后端、数据库、Cookie、身份指纹、在线榜、好友PK、多人、商店、广告、成就、每日任务、复杂声音、实力排名或服务端存档。事件固定为 pageview-merge / portal-click-merge / merge-start / merge-final / merge-gameover / merge-restart，不携带队伍、输入或身份。

纯逻辑测试覆盖 progression、所有分数和连锁、重复合并、spawn/preview、storage、game over；真实 Matter 验证清除旧 body、稳定性和多次本命；浏览器检查 360/390/430/768/1440px、iPhone 类 viewport、Pointer/键盘、reduced-motion、刷新和资源。模拟视口不能当 Android/iOS 真机验收。

F 才追加 enabled:false 注册项。disabled 不产生线上卡片/游戏产物；发布、聚合和 production smoke 的事实证据分开记录，不把已有网站 smoke 当新游戏上线验收。
